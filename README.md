# SBA 4 : TASK MANAGEMENT APP
This task management app allows for users to add tasks with deadlines, assign categories, and update the status of each task. 

In order to work application :
                              -First: Enter a task

                              -Second: Enter a category

                              -Third: Select a deadline

                              -Fourth: Click add task to add task to list
                              
                              -Fifth: Update task's status depending on progress
